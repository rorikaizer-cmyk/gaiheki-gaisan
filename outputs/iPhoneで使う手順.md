# iPhoneで使うための公開手順

この計算ページは、GitHub Pagesという無料の公開サービスを使うと、iPhoneからURLで開けます。

## 1. GitHubにサインインする

パソコンで [GitHub](https://github.com/) を開き、アカウントを作るか、すでにあるアカウントにサインインします。

## 2. 新しい置き場所を作る

右上の「＋」から「New repository」を選びます。Repository name に `gaiheki-gaisan` と入力し、「Public」を選んで「Create repository」を押します。

## 3. このフォルダの中身をアップロードする

作成した画面で「uploading an existing file」を選びます。次のフォルダの中にあるものを、全部アップロードします。

`C:\Users\rorik.DESKTOP-R69NLSJ\Documents\Codex\2026-10-16\referenced-chatgpt-conversation-this-is-an`

アップロード後、「Commit changes」を押します。

## 4. ページを公開する

リポジトリ上部の「Settings」→ 左側の「Pages」を開きます。「Build and deployment」の Source を「Deploy from a branch」にします。Branch は「main」、フォルダは「/(root)」を選び、「Save」を押します。

数分後に表示されるURLが、iPhoneで開くためのURLです。

## 5. iPhoneのホーム画面に置く

iPhoneのSafariで公開URLを開きます。画面下の共有ボタンを押し、「ホーム画面に追加」を選ぶと、ホーム画面からすぐ計算ページを開けます。

> 注意：現在の計算はあくまで概算です。塗料の使用量は、必ず使用する製品の仕様書で確認してください。
